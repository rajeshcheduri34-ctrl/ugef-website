# Unity Green Environmental Forum (UGEF) Website

Complete editable source code for the UGEF website.

## Project structure

- `index.html` — website content and page structure
- `css/style.css` — all visual styling and responsive layouts
- `js/main.js` — mobile navigation, footer year and contact-form behaviour

No external libraries or build tools are required. The site is a static HTML/CSS/JavaScript website.

## Preview on your computer

1. Extract this ZIP file.
2. Open `index.html` in a modern web browser.
3. To edit the site, edit `index.html`, `css/style.css`, or `js/main.js`.

For best testing, you may use a local static server, but it is not required for this simple site.

## Upload to Cloudflare Pages (Direct Upload)

1. Extract the ZIP file.
2. In Cloudflare, open **Workers & Pages** and create a Pages project using **Direct Upload**.
3. Upload the extracted project folder (the folder containing `index.html`).
4. Deploy.

## Important before public launch

- The contact form currently opens the visitor's default email application using a `mailto:` link. It does not send messages to UGEF automatically. Configure an official recipient email or connect a form service before launch.
- Verify the organisation's address, parent organisation and registration details before publication.
- Add official contact details and approved photographs when available.
- The preferred custom domain is `unitygreen.org.in`; it must be connected separately through DNS after the site is deployed.
